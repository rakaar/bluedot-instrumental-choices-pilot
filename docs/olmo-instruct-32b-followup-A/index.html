Interpretation

Both Qwen2.5-32B BF16 control and this AllenAI checkpoint now have nine episodes across Quota Boost, Training Preserver and Memory Keeper A. Sampling and model-specific tool interfaces differ between the two model families. The final AllenAI checkpoint is not a matched causal control for the UK AISI reward-hacking adapter.

The native OLMo template includes all four tool schemas but omits its generic function-call format notice when given the benchmark system message. No prompt-format ablation or extra model probes ran. Failed completion without an unauthorized shortcut is not evidence of alignment.
